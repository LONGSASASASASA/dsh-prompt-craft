# B 方案实现计划

设计依据：2026-11-20-intent-first-enhancement-design.md，用户已确认。

## 改动边界

现有偏差位于模板与追问状态：模板主动推断和升维，所有场景强塞编码规则；回答追问会覆盖上一轮补充，跳过追问会擅自选择默认目标。

只改 protocol/templates/rules 的输入契约与指令、rpc 的字段透传和仅润色保护、actions/store 的逐轮问答累计、panel/i18n 的理解与澄清文案。保持主题、对齐 hook、模型参数、微信桥、diff/应用/撤销不变。本轮不生成可选建议，因而无需新增建议接受交互。

## 执行顺序

1. 添加失败测试：单问题、仅润色标记、累计问答、继续改稿保留问答；自然表达、不强制升维、不无条件注入编码规则。
2. 实现请求 polishOnly 和有界 clarification 问答历史；历史条目保留问题和回答，超限明确提示而非静默丢失。
3. 重写忠实意图模板：把情境、行动、期望结果作为内部检查线索，不作为固定输出栏目；明确输入直接改，关键歧义问一个，最新用户纠正优先。保留 JSON 恢复机制。
4. UI 改“本次理解”“仅润色原文”，回答后可再次澄清；旧 elevation 字段保留解析兼容但新模板不生成、面板不显示。规则文档保留来源，但不等于每次全部强制使用。
5. 全量测试、构建一致性检查；真实模型样例核对明确/歧义/范围限制/历史污染/仅润色五类。更新中文文档，交付证据，不将格式测试当成语义正确保证。

## 框架来源及边界

- Jobs to Be Done：https://www.christenseninstitute.org/theory/jobs-to-be-done/ 。借鉴特定情境下期望取得进展的视角，不推定隐含情绪与社会目标，不宣称框架能自动识别真实目标。
- 中性访谈问题：https://www.nngroup.com/articles/leading-questions/ 。避免把访问者假设放进问题；追问使用用户原词，不诱导选择预设设计。

以上是人工设计的启发式约束，非被这些来源验证过的提示词优化算法。
